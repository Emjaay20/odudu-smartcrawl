# Quick start

Run Odudu with one command and sign in to the console in ten minutes.

By the end you will have a server of your own, an administrator signed in to its console, and a user signed in through the same flow your apps will use.

## What you will do

1. **Start Odudu.** One command brings up the server and its database, with an administrator account made from the email and password you give it.
2. **Sign in to the console.** You meet the same sign-in page a user meets, then the console. The guide [An admin signs in and changes a user](../guides/admin-signs-in-and-changes-a-user.md) shows each request behind it.
3. **Sign a user in.** Send a person through the authorization code flow and read the tokens that come back, as in [Sign a user in](../guides/sign-a-user-in.md).
4. **Change something and see it recorded.** Edit a user from the console and read the audit trail, which the same guide ends with.

## After the quick start

Read [Refresh and end a session](../guides/refresh-and-end-a-session.md) to keep people signed in, and [Concepts](../concepts/index.md) for what a tenant, a client and a token are.
