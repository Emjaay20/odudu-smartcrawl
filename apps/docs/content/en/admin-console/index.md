# Admin console

A tour of the console and one page for each area it manages.

The console signs an administrator in through the same flow your users meet, and keeps the tokens on the server. The browser holds a session cookie and nothing else. Every change an administrator makes is checked against the version they read and recorded in the audit trail.

[An admin signs in and changes a user](../guides/admin-signs-in-and-changes-a-user.md) follows one administrator from sign-in to a change. The routes behind it are recorded in [Console paths](../reference/transcripts/console-paths/index.md).
