# Releasing

This page is for the people who publish Odudu, not for people who run it. If you only run it, you want [Deploying](./deploying.md) and [Upgrading](./upgrading.md).

## Where it stands

No version of Odudu has been published yet. The first release, with a signed container image, a list of its contents and a written release procedure, is the remaining work of P4g, the release this documentation ships with ([roadmap](../roadmap.md)). Until it is done there is no image to pull and no signature to verify, and this page describes no procedure, because one nobody has run is not one to follow.

When the release process exists, this page will hold the steps, and the commands that verify an image's signature will be shown here and on [Deploying](./deploying.md) from the one place that holds them.

## Until then

You can build the image from a copy of the source and run it exactly as [Deploying](./deploying.md) describes, with your own tag in place of a version. [Contributing](../contributing/index.md) says how to get the source and run its checks.
