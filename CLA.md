## How to sign

Open a pull request. The CLA bot comments on it. Reply with one comment holding
exactly this sentence:

```text
I have read the CLA Document and I hereby sign the CLA
```

You sign once. It covers every pull request you send afterwards. To check a
pull request again after signing, comment `recheck`.

## How your consent is recorded

The bot stores your GitHub username, your account ID, the pull request, the
time of your comment and the version of this document in a file on the
`cla-signatures` branch of the repository. The comment itself stays on the pull
request. The Owner and Dependabot do not sign: the Owner holds the rights, and
Dependabot sends version bumps only.
